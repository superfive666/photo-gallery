# 交互与体验

## 用户是谁，在什么处境下用

社团成员，**在手机上**，活动结束后想找自己的照片。多数人只会用一次或几次，
不会读说明文档，也不会重试很多次。所以：

- **一次成功比功能丰富重要。** 首屏就能看懂要干什么。
- **不要有教学步骤。** 上传区本身就是说明。
- **移动端是主场景，桌面端是附带。** 先在 375px 宽度下设计，再向上适配。

## 核心流程（只有三步，不要变多）

```
邀请码 + 同意  →  拍/选自拍（1~3 张）  →  结果网格 → 点开看原图
```

每一步都必须能在不理解「人脸识别」原理的情况下完成。

## 关键交互决策

**主动提供「拍一张」而不只是「选文件」。** `capture="user"` 直接开前置摄像头，
省掉「打开相册 → 翻找 → 选择」这段最容易流失的路径。

**鼓励多传一张，但不强制。** 上传第一张后出现一句提示（「再加一两张不同角度的自拍，
能明显提高找到照片的概率」）。这是最便宜的召回率提升手段，值得占一行文案。
但绝不能变成阻塞条件 —— 强制传 3 张会直接劝退。

**结果按相册分组。** 用户的心智模型是「哪次活动」，不是一个连续的相似度队列。
组内按相似度降序，最可能是本人的排最前。

**不展示相似度分数。** 数字会引来「为什么是 0.43 不是 0.5」的质疑，而这个数字对用户
没有任何可操作性。内部排查看日志就够了。

**客户端先压缩再上传。** 手机原图 4~8MB，移动网络下等待感很强，而识别根本不需要那么高
分辨率。压到长边 1600px 既快又顺带丢掉 EXIF（含 GPS）。

## 加载状态

人脸推理是真的要等（单张 CPU 上 0.2~0.5s，加上传和检索通常 1~3s）。所以：

- 按钮变为「正在检索…」并 disabled，**不要**用全屏遮罩 —— 全屏遮罩让人以为卡死了。
- 超过 5 秒仍未返回时补一句「正在比对照片库，请稍候」，避免用户以为断了。
- 绝不用假进度条。骗人的进度比没有进度更糟。

## 空状态必须分两种

这是最容易被做错、也最影响体验的一处。「没检测到人脸」和「检测到了但没匹配上」
是完全不同的情况，用户该做的事也不同 —— 混成一句「没有结果」会让人无从下一步。

| 状态 | 标题 | 用户该做什么 |
| --- | --- | --- |
| `no_face` | 没有识别到人脸 | 换正面、光线好、脸大一些的自拍 |
| `no_match` | 没有找到匹配的照片 | 换清晰的自拍 / 多传几张；或接受「这些活动里可能没有你」 |

`no_match` 的文案里必须诚实地提到**局限**：站在合影后排、脸太小就是搜不到。
隐瞒这一点会让用户反复尝试并最终认为系统坏了。

## 错误文案

原则：说清**发生了什么** + **现在能做什么**。不暴露技术细节，不用「未知错误」。

| 情况 | 文案 |
| --- | --- |
| 邀请码错误 | 邀请码不正确 |
| 会话过期（401） | 静默回到邀请码页，不弹错误 —— 用户不需要知道「session 过期」这个概念 |
| 限流（429） | 检索次数过于频繁，请稍后再试 |
| 文件过大（413） | 图片过大，请压缩到 10MB 以内（正常不会触发，因为客户端已压缩） |
| 格式不支持（415） | 只支持 JPEG / PNG / WebP / HEIC 格式的图片 |
| 服务端故障（5xx） | 服务暂时不可用，请稍后再试 |

不要在文案里出现：embedding、向量、阈值、聚类、模型 —— 这些是实现细节。

## 隐私告知的呈现

这不只是合规动作，也是让人敢用的前提。

- 告知文案**常驻在上传区附近**，不允许折叠、不允许只放在页脚链接里。
  藏起来的告知等于没有告知。
- 首次进入必须**主动勾选**同意，不预勾。
- 文案说人话：「你的自拍仅用于本次检索，处理完成后立即从内存中销毁，不会被保存到任何位置」，
  而不是「我们依据 PDPA 处理您的个人数据」。
- 提供 opt-out 的联系方式。

## 无障碍

- 语义化标签：`<main>` / `<header>` / `<section>` / `<figure>`，不要一堆 `<div>`。
- 每个纯图标按钮都要 `aria-label`（关闭、移除这张自拍）。
- 错误提示用 `role="alert"`，屏幕阅读器才会播报。
- Lightbox：`role="dialog"` + `aria-modal="true"`，支持 Esc 关闭、方向键翻页，
  打开时锁住背景滚动。
- 图片 `alt` 写实际内容（文件名/用途），不要写「图片」。

## 审查清单

- [ ] 375px 宽度下全流程可完成，无横向滚动
- [ ] 触摸目标 ≥ 44px
- [ ] 加载态不用全屏遮罩、不用假进度
- [ ] 空状态区分 no_face / no_match，且 no_match 诚实说明局限
- [ ] 错误文案不含技术术语，401 静默处理
- [ ] 隐私告知常驻可见，同意不预勾
- [ ] 图标按钮有 aria-label，错误有 role="alert"
- [ ] blob URL 在移除预览时被 `revokeObjectURL` 释放
